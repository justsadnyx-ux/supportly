Run Supportly on a VPS

GitHub Pages hosts these docs only. The bot runs on a real host with a Python process + MongoDB.

Important: this page is documentation

GitHub Pages is static hosting. It serves files only — it cannot run the bot, hold your Discord token, or host MongoDB. To keep Supportly online 24/7, run it on a host that supports long-running processes (a VPS, or Railway / Fly.io / Render, or your Windows VM).

No secrets are stored in this repo. Your token stays in the host environment only.

1. Get a VPS

1Pick a Linux VPS (Ubuntu 22.04 is a safe default). 2 vCPU / 4 GB RAM is plenty for a support bot.
2Note the server IP and root (or sudo) SSH access. Point a domain/CNAME at it if you want (e.g. bot.yourdomain.com).

2. Install dependencies

3Log in, then install Python 3.11 + MongoDB (use the official MongoDB apt repo) and git:
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -   # (optional: node for the launcher)
sudo apt-get update && sudo apt-get install -y git curl gnupg
# MongoDB official key + repo
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.gpg | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" \
  | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update && sudo apt-get install -y mongodb-org

# Python 3.11
sudo apt-get install -y software-properties-common
sudo add-apt-repository -y ppa:deadsnakes/ppa
sudo apt-get update && sudo apt-get install -y python3.11 python3.11-venv python3.11-distutils

3. Clone + configure (keep secrets out of git)

4Clone and create a virtualenv:
git clone https://github.com/justsadnyx-ux/supportly.git
cd supportly
python3.11 -m venv .venv
.venv/bin/pip install -U pip install -r requirements.txt
5Start MongoDB and create .env with your token in the host environment only (never commit it):
sudo mkdir -p /data/db /var/log/mongodb
sudo mongod --fork --logpath /var/log/mongodb/mongod.log --dbpath /data/db --bind_ip 127.0.0.1

cat > .env <<'ENV'
TOKEN=YOUR_DISCORD_BOT_TOKEN_HERE
GUILD_ID=1523251076915265606
SUPPORT_GUILD_ID=1523251076915265606
CONNECTION_URI=mongodb://localhost:27017
UPDATE_CHANNEL_ID=1533409707409018992
STATUS=online
ACTIVITY_TYPE=custom
ACTIVITY_MESSAGE=DM - FOR SUPPORT
DISABLE_AUTOUPDATES=true
ENV
# Restrict file perms:
chmod 600 .env

Tip: on real hosts, prefer injecting `TOKEN`/`CONNECTION_URI` via the host's secret store instead of a file.

4. Keep it alive (replace the local restart loop)

On Windows you used start_supportly.py. On Linux use a process manager so the bot restarts if it crashes.

.venv/bin/pip install pm2   # optional
.venv/bin/python bot.py     # (or wrap it in a systemd unit / supervisor)

Example systemd unit: set ExecStart=/path/supportly/.venv/bin/python /path/supportly/bot.py, Restart=always, environment PYTHONUNBUFFERED=1.

5. Verify

  • Bot status on Discord shows DM - FOR SUPPORT.
  • ? prefix works in Froggy.
  • ?changelog loads from the Pages changelog.
  • ?update reports current vs latest and posts the changelog to #our-bot-updates.
