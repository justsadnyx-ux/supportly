Supportly

Modern Discord support bot · prefix ? · status: DM - FOR SUPPORT

About

Supportly lets your server members message a single DM to reach a staff member. Each conversation becomes an organized Discord thread for support staff — no more lost DMs.

Get support

DM the bot — it is always listening. Your first message creates a private thread that staff can see and join.
