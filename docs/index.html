About

Supportly turns DMs into organized staff threads. Members message one place; staff answer in a private Discord thread that stays attached to their message history. Built for communities that want support without the channel noise.

open source v1.0.8

How it works

1 A member DMs Supportly with their question.
2 A private thread is created in <#1523251076915265606> for your staff.
3 Staff reply in-thread; the member gets the reply in DMs.

Get support

DM Supportly — it is always listening. Your first message opens a thread.

Changelog

Release notes are posted to #our-bot-updates on the support server. The latest version is also served here as changelog.md.

Host it yourself

Supportly runs on any host with Python 3.11 + MongoDB (a VPS, Railway/Fly.io, or your Windows VM). GitHub Pages only serves these docs — it cannot run the bot. See the VPS deployment guide, README, and CONTRIBUTING.
