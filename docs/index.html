About

Supportly turns DMs into organized staff threads. A member messages the bot once; staff reply in a private Discord thread attached to that conversation. Built for communities that want support without the channel noise.

open source v1.1.5

Bot status

This site is static, so it cannot display the bot's live online/offline state by itself. To add a badge, expose any public endpoint that returns {"ok":true} (for example GET https://bot.example.com/health) and paste its URL into the supportly-health-url meta tag in this file (it is empty today). No secrets are stored client-side; the badge only fetches the endpoint you specify.

status badge disabled (set supportly-health-url to enable)

How it works

1 A member DMs Supportly with their question.
2 A private thread is created in #support for your staff.
3 Staff reply in-thread; the member receives the reply back in DMs.

Get support

DM Supportly — it is always listening. Your first message opens a thread.

Changelog

Release notes for the bot are posted to #our-bot-updates on the support server. The latest release notes are also rendered on the changelog page, and the raw file is available as changelog.md.

Host it yourself

Supportly runs on any host with Python 3.11 + MongoDB — a VPS, Railway/Fly.io, or a local machine. GitHub Pages only serves these docs; it cannot run the bot itself. See the VPS deployment guide, the README, CONTRIBUTING, and the FAQ.
