How do I get support?

The bot status is DM - FOR SUPPORT. DM it; the first message opens a private thread in the support server and staff reply back to you there.

Why post to #our-bot-updates?

That is this bot's update channel. New releases go there (never DMed to members).

What does ?update do?

Read-only check. It posts the latest changelog to #our-bot-updates and reports it in chat. It does not pull code, restart, or announce in the channel you typed.

Are updates automatic?

Yes. Every 15 min and once after boot the bot compares its version to the changelog; if newer, it runs git pull, posts an update note to #our-bot-updates, and restarts. See the changelog for the fix history (v1.1.3 stop-the-hang, v1.1.5 stop-the-crash).

Can I host my own?

Yes: Python 3.11, MongoDB, a Discord bot token, and the support server. GitHub Pages only serves these docs. See the VPS guide.

Premium / roles?

Gated behind the Premium role in the support server; checked at runtime. No license key.

Heroku / Docker / PM2 / systemd?

Auto-updates work everywhere without a token except Heroku, where you must set github_token (without it, auto-updates disable themselves rather than failing). Docker is auto-disabled.
